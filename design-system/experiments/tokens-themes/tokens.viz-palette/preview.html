Data-visualisation palette (viz-1…4)

Experiment · tokens-themes · not adopted

Adds four categorical chart colours per theme as tokens (`viz-1`…`viz-4`), validated for colour-vision deficiency and ≥ 3:1 against surface in both themes. Charts can use `stroke-viz-1`, `bg-viz-2` and so on instead of local hex.

Trend chart

Before: v2.0.0 has no chart palette — the proposal specimen defines local CSS variables. After: the series use the viz tokens (stroke-viz-1…) and switch with the theme.
