# EmptyState

Quiet block for "nothing here yet": `bg-elevated`, `rounded-lg`, title + description + optional action.

Source: `src/components/creatorco/empty-state.tsx`. Props: `title`, `description?`, `action?`, `className?`.

## Variants shown

No data yet (no signals) · nothing to do (all platforms connected) · unavailable with an action (signals not available → Back to Passport).

## Rules

Say why it's empty and what the creator can do. If nothing can be done, don't show an action and don't count it against the creator (P-03).
