# ProposedVerificationStates

P-01 — attribute-level verification with five states: self-declared, verified, derived, missing, needs attention.

**Status: proposed — not adopted.** Built only from existing components and tokens; see `PROPOSALS.md`.

Each state has its own mark and wording pattern; verification applies to individual attributes, never the whole Passport ("3 of 6 details verified"). Today's component has four states (no **derived**).
