# Screens

Screenshots of the running app (Stage 07 build, demo seed data), captured in every combination of **iPhone 390pt @2x / desktop 1280px** and **dark / light**. File names: `<screen>-<mobile|desktop>-<dark|light>.webp`.

The `components/Screen*` cards show each screen with mobile and desktop side by side and switch with the page theme. Screens that are not built yet (status reveal, eligibility result, membership-card screen, invitation) are compositions of real components in the **Proposed** group.

Recapture after UI changes; the demo accounts are seeded by `npm run db:reset`.
