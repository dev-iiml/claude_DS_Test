# Changelog

## Versioning — 3 Oct 2026

- The v2 baseline was formalized as **release v2.0.0** from the developer's active files: 7 modules, 37 files, SHA-256 per file. It includes the developer's later `app-nav.tsx` change (new console icons, most-specific active item) and the `progress.tsx` `label` prop. Nothing in `src/` changed. v2.0.0 is the active release.
- Added `versioning/` (the `ds.mjs` tool and `modules.json`), `releases/` (manifest and immutable snapshots) and `experiments/` (ten proposed experiments across all seven modules, each with patch, preview, before/after, changelog and dependency notes).
- Found while setting this up: Tailwind's automatic source scan includes `design-system/`, so 169 unused utility classes from the viewer and preview files are in the app stylesheet. This has no visual effect. The `tokens.source-isolation` experiment fixes it and is proposed, not applied.
- `.prettierignore` also skips `design-system/releases` and the generated experiment previews, so formatting can never alter an immutable snapshot.

### 4. Contrast fixes (non-text, WCAG 1.4.11)

`line-strong` (~1.5–1.8:1) was marking control states. Now `input-border` (≥ 3:1 on every ground, both themes):

- SwitchRow off-track: `bg-line-strong` → `bg-input-border` (the white thumb was 1.7:1 against the light off-track).
- ProgressSteps upcoming segments: `bg-line-strong` → `bg-input-border`.
- RequirementChecklist unmet ring: `border-line-strong` → `border-input-border`.
- Light `input-border` darkened (see §2).

Decorative uses of `line`/`line-strong` (card rings, chip rings, chip hover, progress track) remain and are documented as decorative.

### 5. Tooling and tests

- `src/lib/cn.ts`: tailwind-merge now knows the token utilities (type, radius, shadow, spacing names) — without it `cn("text-body", "text-ink")` would drop the size.
- `globals.css`: maps type, sizes, radius, shadows and `ease-spring` to Tailwind; adds `--color-input-border`, `--color-thumb`, `--color-membership-*`; `press` utility; reduced motion also removes `:active` scale.
- `tests/unit/design-tokens.test.ts`: + control boundaries and states, filled-control labels, selection, translucent bar composite, membership opacities, touch targets, `line-strong` guard, "token utilities exist" scan, `tokens.json` sync. (Declaration regex now includes digits.)
- `package.json` `tokens` script also writes and formats `design-system/tokens.json`.
- `design-system/viewer/build.mjs` (new, dev-only): builds `components/bundle.js` and `bundle.css` from the real components with esbuild and `@tailwindcss/postcss` (no new dependencies). Run `node design-system/viewer/build.mjs`.
- `design-system/viewer/build-html.mjs` (new, dev-only): writes `design-system/design-system.html`, a single self-contained offline viewer of the whole system.
- Ignores: `.prettierignore` skips `design-system/components/bundle.*`, `design-system/design-system.html`, the `preview.html` documents and `design-system/archive`; `eslint.config.mjs` ignores `design-system/**`; `tsconfig.json` excludes `design-system`. Markdown, JSON and the viewer sources stay Prettier-formatted.

### 6. Left as intentional exceptions

| Value                                                                                                    | Why                                                 |
| -------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `text-[40px] sm:text-[56px] lg:text-[64px]`, `leading-[1.04]`, `tracking-[-0.035em]`                     | Responsive display hero — not part of the iOS scale |
| AuthShell statement `text-[40px] leading-[1.08]`                                                         | Brand panel statement                               |
| Wordmark `text-[22px]` / `text-[19px]`; card name `sm:text-[24px]`                                       | Brand mark sizes, independent of the type scale     |
| `text-[0.8rem]` CreatorStatusBadge, `text-[0.65rem]` checklist tick, `text-[14px]` mono audit events     | Glyph-level fine tuning                             |
| `rounded-[11px]` / `rounded-[9px]` segmented, `rounded-[7px]` checkbox                                   | Derived from outer radius minus padding             |
| `size-[18px]` icons in buttons / sidebar                                                                 | Icon size (no icon-size scale yet)                  |
| Tracking `0.02em` / `0.12em` / `0.14em` / `0.18em` / `0.3em` (labels, card), `--tracking-eyebrow` 0.08em | Typographic detail; candidates for a tracking scale |
| `w-[72%]` Access strip items, `min-h-[180px]` Access tiles, `max-w-[55%]` ListRow value                  | Layout proportions                                  |
| `aspect-[1.586/1]` membership card                                                                       | ISO ID-1 card ratio                                 |
