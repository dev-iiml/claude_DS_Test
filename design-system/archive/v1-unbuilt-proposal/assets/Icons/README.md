# Icons

The approved CreatorCo icon set: Lucide (ISC licence) outline icons, 24px grid, **1.5px stroke**, round caps and joins.

- Files are single-ink SVGs drawn in `#121110` (the Chalk `text` colour). In the app, use `lucide-react` with `strokeWidth={1.5}` and `currentColor` so icons follow `text`, `text-muted` or a semantic colour; on the Onyx theme the ink becomes `#f2eee6`.
- Sizes: 20px default, 16px in dense tables and badges, 24px in empty states and feature rows.
- Platform glyphs are neutral: `camera` (photo platforms), `video` (video platforms), `mic` (audio/podcast). Always pair with the platform name in text.
- Need an icon that isn't here? Pick it from Lucide, keep 1.5px stroke, and add it to this group.
