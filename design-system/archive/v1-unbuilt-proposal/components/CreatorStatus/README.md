# CreatorStatus

Creator Status — **Member → Onyx → Icon** — reflects professional standing in the network. It is shown with *materials* (chalk, onyx, smoked titanium), never with numbers, limits or money.

## Badge
Mono caps on the tier material with a tier-mark dot. Sizes: 28px (default). Screen readers hear "Creator Status: Onyx".

## Tier card
Material swatch, tier name in display type, one line on what it means, and what it brings in **access** terms (drops, events, concierge).

| Tier | Material | Mark | Feeling |
|---|---|---|---|
| Member | matte chalk `tier-member-base` | brass `tier-member-mark` | welcome, open door |
| Onyx | matte black `tier-onyx-base` + edge line | graphite `tier-onyx-mark` | recognised, established |
| Icon | smoked titanium `tier-icon-base`→`tier-icon-sheen` | one Rani line `tier-icon-mark` | by invitation, rare, quiet |

## Hard rules
- Status is not creditworthiness. No ₹, no "limit", no eligibility copy anywhere near a tier badge or tier card.
- Progress toward a tier is described in professional terms ("Verified brand work", "Complete Passport"), never "spend more" or "borrow more".
- Icon is never advertised as a target to grind for. It is offered by invitation.
