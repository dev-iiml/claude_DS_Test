# Screen04StatusReveal

**Status tier reveal.** The signature moment: the card rises out of the dark on `ease-reveal` (1.2s, a slight 3D tilt settling flat), then the eyebrow, tier name and one line fade up. No confetti, no sound, no numbers, no "level up".

- Onyx reveal: the card, the word, the reason (professional work), and a footnote that status never changes financial eligibility.
- Icon is an **invitation**, accepted or declined — never "unlocked".
- Plays once; afterwards the card simply sits in place. Reduced motion: no rise, instant.
