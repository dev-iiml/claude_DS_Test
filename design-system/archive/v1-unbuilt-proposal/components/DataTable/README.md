# DataTable

Tables for the risk console and creator history. Uppercase 11px headers on `surface-sunken`, 13px rows, 1px `border` rules, tabular numerals right-aligned. Toolbar above: search, filter chips, sort; pagination below.

- Row height 40px (dense) — 48px in creator-facing tables.
- Selected row: `surface-sunken`. Status cells use badges with words.
- Mono for IDs, reason codes and model versions.
- Long tables scroll horizontally inside `tablewrap`; the first column sticks.
