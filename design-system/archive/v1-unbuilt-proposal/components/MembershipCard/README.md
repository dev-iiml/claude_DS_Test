# MembershipCard

The virtual membership card — one artwork per tier, ID-1 proportions (1.586:1), radius-card, `shadow-card`.

## Anatomy
Wordmark (placeholder) top-left · tier name in mono caps top-right · the Door hairline in the tier mark colour · member name in display type · member number + "Member since" in mono caps.

## Rules
- A membership card is **not a payment card**: no chip, no network mark, no card number, no "Issued by". Those belong only to the co-branded card (see CoBrandCard).
- Tier materials appear only here, on tier badges and on the status reveal.
- Card art may tilt 6–8° on device motion (parallax, off under reduced motion). No holographic foil, no glitter.
