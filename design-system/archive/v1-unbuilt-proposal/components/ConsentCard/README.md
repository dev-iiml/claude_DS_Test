# ConsentCard

Consent is **purpose-specific**: one card per purpose, written in plain language, with what data, why, who sees it, for how long, and how to withdraw. Each card shows its version.

## Anatomy
Icon + purpose title · one-sentence why · "We will use" list (3–5 lines) · "We won't" line · footer with version label (`Consent v2.1 · 3 Oct 2026`), "Read full text" link and the action.

## Actions
- Give: primary "I agree" (never pre-ticked, never bundled).
- After giving: badge "Active since 3 Oct", "View receipt", destructive-quiet "Withdraw".
- Withdraw opens a dialog that says exactly what stops and what CreatorCo must keep by law.

## Receipt
A tear-edge receipt with purpose, version, timestamp (IST), reference (mono), channel, and a download link.

Available in English and Hindi; the Hindi version is a full translation, not a summary.
