# Screen09RiskConsole

**Internal risk console.** Same tokens, higher density: 13px text, 36px controls, 40px rows, mono for IDs/codes/versions. A queue table with completeness, Traditional vs Creator-enhanced recommendation and flags; a detail panel with the side-by-side comparison, component scores, reason codes (signed + / · / −, with words), fraud flags, completeness, model version, consent version and the audit trail.

Expression of the brand here is **precision, not flair**: no display type beyond the panel name, no Rani, no tier materials, no photography.

Analysts' actions are recommendations to the partner ("Recommend to partner"), never "Approve loan".
