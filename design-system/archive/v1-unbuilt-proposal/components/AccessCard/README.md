# AccessCard

Opportunity / access cards present curated drops, events and experiences. A photo (or placeholder) on top, a ticket notch, then title, meta and a single action.

## Rules
- Access is about **membership**, not money: never show credit, limits or eligibility on an access card.
- A tier requirement shows as the tier badge ("Onyx and above"), never as a lock with a price.
- Scarcity is stated plainly ("40 places"), never with countdown timers or flashing.
- Actions: "Request access", "Join waitlist", "View details". Results: "Requested", "Confirmed".
