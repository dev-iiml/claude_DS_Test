# Screen02Dashboard

**Creator dashboard (mobile).** Priority order, top to bottom: identity & status → Creator Passport → financial eligibility → access → opportunities → rewards.

- Identity leads: first name in display type with a Rani full stop (the one accent), Creator Status badge, verification.
- Financial eligibility is a quiet, opt-in card with a secondary button and the disclosure in the footer. No amounts on the dashboard; debt never dominates.
- Access and opportunities carry the energy — photography, places, dates.
