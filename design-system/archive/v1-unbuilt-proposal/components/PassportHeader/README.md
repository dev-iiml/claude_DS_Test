# PassportHeader

The Creator Passport header: who you are professionally, verified. Avatar (photo), name in display type, handle and city, verification line, Creator Status badge, and primary categories.

- The badge sits beside the name as identity — it never sits next to money.
- "Verified" requires a real check (ID or platform connection); use `badge-check` + word.
- No follower counts in the header. Business facts lead.
