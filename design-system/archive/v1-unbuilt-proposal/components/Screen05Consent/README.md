# Screen05Consent

**Consent screen.** Purpose by purpose, in plain language, each with its own version, its own yes/no and a receipt afterwards — never a wall of legalese, never one bundled checkbox. Financial-eligibility consent is optional and offers "Not now" as an equal action.

Shown in English and Hindi (full translation; Devanagari at 15px with 1.75 line-height).
