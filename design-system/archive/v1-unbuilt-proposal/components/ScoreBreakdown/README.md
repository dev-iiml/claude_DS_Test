# ScoreBreakdown

Component scores as horizontal bars, 0–100, value labelled at the end. Used for the creator's "what this is based on" and, side by side, for **Traditional vs Creator-enhanced** in the risk console.

- Traditional = `chart-1` (brass), Creator-enhanced = `chart-2` (slate), always with a legend and column headers.
- Components that the traditional model cannot see show "n/a", not zero.
- Never a radial gauge, speedometer or "credit score" dial.
