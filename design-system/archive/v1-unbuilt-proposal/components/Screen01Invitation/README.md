# Screen01Invitation

**Landing / invitation moment.** The "Centurion moment" for everyone: an inverse ground, the Door drawn in Rani, a display headline with one italic word, and who invited you. Then a calm join step (mobile + OTP + terms).

- Motion: the Door draws (1.6s, `ease-reveal`), then eyebrow → headline → body fade up, 200ms apart. Reduced motion: everything is simply there.
- One signature (Rani) button. No timers, no "limited spots" pressure; the expiry date is stated quietly.
