# EligibilityResult

Financial eligibility is presented as a calm, transparent **recommendation**, not an approval. It is visually structurally separate from Creator Status: neutral ink and surfaces, slate data colour, an info-tinted disclosure. No tier materials, no Rani, no celebration.

## Anatomy (top to bottom)
1. Eyebrow "CreatorCo recommendation" + badge "Proposed eligibility".
2. A **range**, not a single number, in `num-xl` with Indian formatting ("₹1,50,000 – ₹2,00,000").
3. Plain-language summary: what this is based on (Financial Capacity, earnings consistency, documentation).
4. Factor breakdown (ScoreBreakdown) — what helped, what's missing. Follower count is explicitly not a factor.
5. Disclosure panel (always visible, never collapsed): "Subject to partner-lender approval. The final offer, rate and terms are decided by [Partner Bank]."
6. Actions: primary "Continue to [Partner Bank]" or "Check financial eligibility again later"; secondary "How this was calculated".

## Never
"Approved", "Guaranteed", "Instant", "You deserve ₹X", confetti, upward-arrow hype, countdowns, or the tier badge on this screen.
