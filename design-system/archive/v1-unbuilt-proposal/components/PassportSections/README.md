# PassportSections

Passport body sections, each a card with a clear title, a short line on why it matters, and its items:

- **Identity** — legal name (masked), PAN/GST status (never the number), verification dates.
- **Connected platforms** — ConnectedAccountChips with connection state.
- **Professional history** — a timeline of roles and milestones.
- **Brand relationships** — partners with category, years and "repeat" marker; amounts never shown publicly.

Completeness shows as a quiet meter + "2 sections left", not a gamified score.
