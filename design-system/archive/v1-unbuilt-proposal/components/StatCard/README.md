# StatCard

One figure, one label, optional delta and sparkline. Figures use `num-lg` tabular numerals and Indian formatting (₹1.5L above ₹1,00,000 in compact contexts, full ₹1,50,000 in detail).

- Deltas pair an arrow + sign + word ("+12% vs last quarter"), coloured `success`/`danger` only when up/down truly means good/bad.
- **Never** a follower count as the hero figure. Business figures lead: earnings consistency, brand partners, Passport completeness.
