# Screen08MembershipCard

**Membership card.** The virtual card for the member's tier, the member number in mono, and what the card opens — in access terms. A segmented control previews the three tier artworks (locked tiers show the art dimmed with "By invitation" for Icon).

The future co-branded payment card is shown alongside to make the separation explicit: issuer line, chip and network zones, cardholder-chosen finish, no tier material.
