# EmptyState

EmptyState is a dashed, quiet block that explains why something is empty and, optionally, offers one action.

Source: `src/components/creatorco/empty-state.tsx`.

## Use
- "No social accounts connected yet" in the Connected accounts card.
- Say what is missing and what happens next in plain words; one secondary action at most.

## Props
`title`, `description?`, `action?`, `className?`
